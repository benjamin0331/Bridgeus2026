1.	使用者登入與系統存取模組
使用者進入系統時，需先完成基本的帳號登入或註冊流程，以取得系統操作權限。此階段僅處理身分驗證與存取控制，不涉及任何議題選擇或立場量測，以避免在對話開始前對使用者產生干擾。
2.	議題選擇與立場量測模組
使用者在主動啟動配對流程後，系統才會依其所選議題顯示對應的立場量表與問題。使用者的回應結果會即時向量化，作為後續配對與分析之依據。
3.	異質立場配對與對話代理人生成模組
系統依據使用者的立場量測結果，計算立場差異程度，並進行對話配對。配對對象可能為另一位真人使用者，或為系統所生成的 AI 對話代理人。
當配對對象為 AI 時，系統會根據議題與立場差異，結合預先設定的提示詞結構與檢索增強生成（RAG）機制，生成具對立立場的回應內容。
4.	結構化對話引導與即時控制模組
對話進行期間，系統會限制單次回應長度與討論主題範圍，以降低對話偏離議題的情形。同時，系統會即時分析對話內容，辨識高情緒強度或明顯偏離議題的語句，並於必要時提供提示，引導對話回到討論範圍內。
5.	語意分析與概念認知網路圖模組
系統會即時分析對話文本的語義距離，並依分析結果更新概念認知網路圖。
該圖以力導向圖呈現，節點代表單一發言，節點間距離對應其語義關係，使對話中立場接近或分歧的變化能以拓撲結構直接觀察。
6.	資料儲存與研究分析模組
系統將保存使用者的立場量測結果、對話內容與分析資料，作為後續人機對話與人際對話比較分析之研究資料來源。
