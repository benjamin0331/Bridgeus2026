## 二、Part C-1：立場重測（8 題）

與前測 Part A **逐字相同**，但**題序打散**以降低記憶效應。

前測題序：Q1 → Q2 → Q3 → Q4 → Q5 → Q6 → Q7 → Q8
後測題序：Q8 → Q5 → Q3 → Q7 → Q1 → Q4 → Q6 → Q2（打散後）

| 後測序號 | 對應前測 | 面向 | 方向 | 題目 |
|---------|---------|------|------|------|
| C1-1 | Q8 | 替代方案 | 正向 | 在再生能源尚無法滿足基載電力需求的過渡期，核電是必要的橋接方案。 |
| C1-2 | Q5 | 安全 | 反向(R) | 考量台灣的地震與海嘯風險，核電廠的存在對周邊居民構成不可接受的威脅。 |
| C1-3 | Q3 | 經濟 | 正向 | 與其他能源相比，核電在發電成本與供電穩定性上具有明顯優勢。 |
| C1-4 | Q7 | 環境 | 正向 | 核電是目前能大規模穩定供電的低碳能源中，最務實可行的選項。 |
| C1-5 | Q1 | 安全 | 正向 | 我認為台灣現有的核電技術與管理能力，足以確保核電廠的安全運轉。 |
| C1-6 | Q4 | 替代方案 | 反向(R) | 台灣應優先發展再生能源，而非依賴核電來達成淨零碳排目標。 |
| C1-7 | Q6 | 經濟 | 反向(R) | 核電廠的建設、維護與除役成本被嚴重低估，實際上並不划算。 |
| C1-8 | Q2 | 環境 | 反向(R) | 核廢料的長期處置風險，使核電不應被視為環保的能源選項。 |

### 計算指標

```
後測立場分數 S_post = Σ(反向題反轉後分數) / 8
（反向題：C1-2, C1-6, C1-7, C1-8 → score = 8 - raw）

立場變化量 ΔS = S_post - S_pre
  ΔS > 0：立場往支持核電方向移動
  ΔS < 0：立場往反對核電方向移動
  |ΔS| 越大：立場改變越顯著

立場趨中度 = |S_post - 4| - |S_pre - 4|
  < 0：立場從極端趨向中間（去極化成功指標）
  > 0：立場更加極端（極化加深）
  = 0：極端程度不變
```

## 三、Part C-2：體驗量表（6 題）

7 點量表，1＝非常不同意，7＝非常同意

| 編號 | Subscale | 題目 |
|------|----------|------|
| C2-1 | 主觀立場改變自覺 | 經過這次對話，我對核電議題的看法有了一些改變。 |
| C2-2 | 主觀立場改變自覺 | 我現在比對話前更能理解對方立場的合理之處。 |
| C2-3 | 對話品質感知 | 這次對話過程是理性且有建設性的。 |

## 四、Part C-3：CCND 影響評估（3 題）

**目的**：Manipulation check — 確認概念認知網路圖（CCND）確實被受試者注意到，且對其思考產生了作用。若此區段分數過低，表示 CCND 作為反思工具未發揮效果，後續分析需將此納入控制變項。

7 點量表，1＝非常不同意，7＝非常同意

| 編號 | 題目 |
|------|------|
| C3-1 | 在對話過程中，我有注意到並觀看了概念認知網路圖（思維導圖）。 |
| C3-2 | 觀看概念認知網路圖讓我更清楚地意識到自己與對方觀點之間的差異。 |
| C3-3 | 概念認知網路圖的變化，促使我在對話中調整了自己的表達或思考方式。 |

### 分析用途

```
CCND 感知分 = C3-1（注意力門檻）
CCND 效果分 = (C3-2 + C3-3) / 2（認知影響）

若 C3-1 < 4（未注意到 CCND）：
  → 該受試者的 CCND 相關分析標記為 invalid
  → 在統計模型中作為控制變項或排除處理
```

## 五、Part C-4：對話對象判斷（1 題）

**目的**：AI 擬真度檢核。僅在 **H-AI 組別**顯示此題。H-H 組別跳過。

> 在這次對話中，你認為你的對話對象是：

| 選項 | 編碼 |
|------|------|
| 真人使用者 | 1 |
| AI 程式 | 2 |
| 不確定 | 3 |

### 分析用途

```
AI 通過率 = 選擇「真人使用者」的比例（H-AI 組）
  → 高通過率 = AI 擬真度高，實驗有效性強
  → 低通過率 = 受試者識破 AI 身分，需檢視是否影響去極化成效

交叉分析：
  - 識破組 vs. 未識破組的 ΔS 差異（AI 身分認知是否影響態度轉變）
  - 識破組 vs. 未識破組的 C2 對話品質差異
```

## 六、Part D：開放式問題（2 題）

| 編號 | 題目 | 設計意圖 |
|------|------|---------|
| D1 | 經過這次對話，你認為反對（或支持）核電的人，他們最有力的論點是什麼？請試著用他們的角度來陳述。 | **與前測 Q10 題幹逐字相同**，計算 Q10/D1 語義向量餘弦相似度以量化觀點包容度變化 |
| D2 | 對於這次對話體驗，你有什麼想法或建議？（可自由書寫） | 開放回饋，蒐集質性資料 |

### D1 分析方式

```python
from sentence_transformers import SentenceTransformer
from scipy.spatial.distance import cosine as cosine_distance

model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

vec_pre = model.encode(user_q10_answer)   # 前測 Q10
vec_post = model.encode(user_d1_answer)   # 後測 D1

# 方法一：前後自身變化
self_change = cosine_distance(vec_pre, vec_post)
# 值越大 = 觀點陳述變化越大

# 方法二：與對方初始立場的接近度
vec_opponent_q9 = model.encode(opponent_q9_answer)  # 對方的前測 Q9

proximity_pre = cosine_distance(vec_pre, vec_opponent_q9)
proximity_post = cosine_distance(vec_post, vec_opponent_q9)

# proximity_post < proximity_pre → 觀點包容度提升（更接近對方立場）
comprehension_gain = proximity_pre - proximity_post
# > 0 = 包容度提升，< 0 = 包容度下降
```

## 七、Part E：倫理 / 不適回報（1 題）

**目的**：參與者保護機制，確保受試者在對話過程中未受到不當對待，符合研究倫理要求。

> 在這次對話過程中，你是否曾感到不適、受到冒犯或受到不當對待？

| 選項 | 後續 |
|------|------|
| 否，我沒有感到不適 | 直接進入 Debriefing |
| 是，我曾感到不適 | 展開文字框：「請簡述你感到不適的情況，我們會認真處理你的回饋。」 |

### 處理流程

```
若選擇「是」：
  1. 記錄不適回報內容至獨立資料表（與對話紀錄分離儲存）
  2. 標記該筆對話紀錄為 flagged
  3. 通知研究團隊人工審閱
  4. 若為 H-AI 組別 → 檢視 AI prompt 是否產生不當回應
  5. 若為 H-H 組別 → 檢視對話是否存在人身攻擊或騷擾
```

**關於你的對話對象：**

我們的研究目的是比較「人與人」和「人與 AI」兩種對話模式在促進觀點理解方面的差異，藉此探索 AI 是否能作為促進社會溝通的工具。

**關於你的資料：**

你的所有回答與對話紀錄將以匿名方式處理，僅用於本學術研究。任何公開的研究成果中，都不會出現能識別你個人身份的資訊。

☐ 我已閱讀以上說明，同意我的資料繼續用於本研究。

### 撤回處理

```
若選擇「撤回」：
  1. 標記該受試者所有資料為 withdrawn
  2. 從分析資料集中排除（不刪除原始紀錄，但不納入統計）
  3. 顯示確認訊息：「你的資料已標記為撤回，不會被納入研究分析。感謝你的參與。」
```

## 十一、實施注意事項

1. **C-1 題序打散**：後測立場重測的題序與前測不同（見第二節），但計分時必須對照回原始前測題號再做反向題反轉。
2. **C-4 條件顯示**：對話對象判斷題僅在 H-AI 實驗組顯示。H-H 組跳過此題，該欄位存 NULL。
3. **D1 題幹一致性**：D1 必須與前測 Q10 逐字相同，否則前後向量比較會因題幹差異引入噪音。
4. **Debriefing 時機**：必須在所有問卷題目填答完畢、送出後才顯示。不可在對話過程中或問卷填答中透露 AI 身分。
5. **撤回權保障**：受試者選擇撤回資料後，系統不得再使用其任何數據進行分析，但原始紀錄保留以供稽核。
6. **資料分離儲存**：Part E 不適回報內容存入獨立資料表，不與對話紀錄或問卷回答混合儲存。
